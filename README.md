# ПЕНАЛЬТИ

Онлайн-дуэль для двух игроков: нападающий выбирает точку удара, вратарь перемещается по воротам в реальном времени.

## Запуск

Нужен Node.js 20 или новее.

```sh
npm install
npm start
```

Откройте `http://localhost:3000`, создайте комнату и отправьте код второму игроку. Для игры с другого устройства оба игрока должны открыть сервер по одному и тому же сетевому адресу.
